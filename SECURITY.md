# Security policy

This policy covers every repository in the Ministry of Agriculture and Irrigation (MoAI-FGS) organization on GitHub.

## Reporting a vulnerability

If you find a security vulnerability in any Ministry system, please report it privately:

- Email: [ict@moa.gov.so](mailto:ict@moa.gov.so), with the subject "Security report"
- Or use "Report a vulnerability" on the repository's Security tab, where it is available

Please do not open a public issue, pull request or discussion about a vulnerability.

Include:

- the system or repository affected
- a description of the issue and its possible impact
- the steps to reproduce it
- your name and how to contact you (optional)

## What to expect

- We will acknowledge your report within 5 working days.
- We will keep you informed while we investigate and fix the issue.
- We ask that you give us reasonable time to fix the issue before you disclose it.

Please do not access, change or delete data that does not belong to you, and do not disrupt Ministry services while testing.
